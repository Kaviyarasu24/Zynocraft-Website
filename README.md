# Zynocraftx Technology

Marketing site for Zynocraftx Technology — software engineering, AI, and digital products.

Built with Vite, React, TypeScript, Tailwind CSS, React Router, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build

## Contact form

The contact form uses [Web3Forms](https://web3forms.com). See [contact.md](contact.md) for setup.
